==================================================================
   COMO ADICIONAR QUESTÕES COM ORDEM PERSONALIZADA
==================================================================

O sistema agora permite que você defina a ordem de exibição dos elementos
na tela conforme você os adiciona no código!

------------------------------------------------------------------
MÉTODOS DISPONÍVEIS:
------------------------------------------------------------------

1. q.addTextoApoio("texto")   -> Adiciona um texto de apoio
2. q.addImagem("nome_imagem")  -> Adiciona uma imagem
3. q.addReferencia("fonte")    -> Adiciona uma referência/fonte (itálico, menor, à direita)
4. q.addEnunciado("pergunta")  -> Adiciona o enunciado da questão

A ORDEM QUE VOCÊ CHAMA ESSES MÉTODOS É A ORDEM QUE APARECE NA TELA!

------------------------------------------------------------------
EXEMPLO 1 - TEXTO, DEPOIS IMAGEM, DEPOIS ENUNCIADO:
------------------------------------------------------------------

Questao q1 = new Questao();
q1.setArea(DatabaseHelper.AREA_LINGUAGENS);
q1.setAno(2024);
q1.setNumero(1);
q1.setIdiomaEstrangeiro("ingles");

// ORDEM DE EXIBIÇÃO NA TELA:
q1.addTextoApoio("Oh, so we can hate each other and fear each other...");
q1.addReferencia("KEYS, A. Here. Estados Unidos: RCA Records, 2016.");
q1.addEnunciado("Nessa letra de canção, o marcador 'instead of' introduz a ideia de");

q1.setAlternativaA("mudança de comportamento.");
q1.setAlternativaB("panorama de conflitos.");
q1.setAlternativaC("rotina de isolamento.");
q1.setAlternativaD("perspectiva bélica.");
q1.setAlternativaE("cenário religioso.");
q1.setRespostaCorreta("A");
databaseHelper.inserirQuestao(q1);

RESULTADO NA TELA:
1. Texto de apoio (caixa com fundo)
2. Referência (itálico, à direita)
3. Enunciado

------------------------------------------------------------------

1. Imagem
2. Texto de apoio

------------------------------------------------------------------
EXEMPLO 3 - MÚLTIPLOS TEXTOS E IMAGENS INTERCALADOS:
------------------------------------------------------------------

Questao q3 = new Questao();
q3.setArea(DatabaseHelper.AREA_HUMANAS);
q3.setAno(2024);
q3.setNumero(50);

// Você pode intercalar elementos como quiser!
q3.addTextoApoio("Primeiro texto de apoio sobre terremotos...");
q3.addReferencia("Fonte 1: CNN Brasil, 2021.");

q3.addTextoApoio("Segundo texto sobre tremores no Amazonas...");
q3.addReferencia("Fonte 2: G1 Globo, 2021.");

q3.addImagem("mapa_brasil");  // Imagem no meio dos textos

q3.addTextoApoio("Terceiro texto sobre SP...");
q3.addReferencia("Fonte 3: R7 Notícias, 2021.");

q3.addEnunciado("As diferenças entre os eventos geológicos decorrem de:");

q3.setAlternativaA("Planícies costeiras.");
q3.setAlternativaB("Bacias continentais.");
q3.setAlternativaC("Zonas de subducção.");
q3.setAlternativaD("Áreas de denudação.");
q3.setAlternativaE("Vertentes escarpadas.");
q3.setRespostaCorreta("C");
databaseHelper.inserirQuestao(q3);

RESULTADO NA TELA:
1. Primeiro texto
2. Primeira referência
3. Segundo texto
4. Segunda referência
5. Imagem
6. Terceiro texto
7. Terceira referência
8. Enunciado

------------------------------------------------------------------
COMPATIBILIDADE:
------------------------------------------------------------------

As questões antigas que usam os métodos antigos continuam funcionando:
- setEnunciado()
- setTextoApoio()
- setFonte()
- setImagens()
- setTextoApoio1(), setTextoApoio2(), etc.

O sistema detecta automaticamente e exibe corretamente!

------------------------------------------------------------------
DIFERENÇAS VISUAIS:
------------------------------------------------------------------

1. TEXTO DE APOIO (addTextoApoio):
   - Caixa com borda
   - Texto tamanho normal (14sp)
   - Cor escura

2. REFERÊNCIA (addReferencia):
   - Sem caixa
   - Texto menor (11sp)
   - Itálico
   - Alinhado à direita
   - Cor cinza

3. IMAGEM (addImagem):
   - Imagem centralizada
   - Ajustada ao tamanho da tela

4. ENUNCIADO (addEnunciado):
   - Aparece onde você colocar
   - Texto normal

------------------------------------------------------------------
DICAS:
------------------------------------------------------------------

✓ Use addReferencia() logo após addTextoApoio() para manter as fontes juntas
✓ Você pode adicionar quantos elementos quiser
✓ Não há limite de ordem ou quantidade
✓ Teste diferentes ordens para ver qual fica melhor
✓ O enunciado geralmente fica no final, mas não é obrigatório

------------------------------------------------------------------
CONVERSÃO DE QUESTÃO ANTIGA PARA NOVA:
------------------------------------------------------------------

ANTES (ordem fixa):
```java
q1.setTextoApoio("texto");
q1.setFonte("fonte");
q1.setEnunciado("pergunta");
q1.setImagens("img1", "img2");
```

DEPOIS (ordem personalizável):
```java
q1.addTextoApoio("texto");
q1.addReferencia("fonte");
q1.addImagem("img1");
q1.addImagem("img2");
q1.addEnunciado("pergunta");
```
